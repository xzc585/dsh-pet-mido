# dsh-pet（米豆衍生版插件目录）

一只住在 DeepSeek Harness 里的桌面宠物。本目录是插件本体，种类「米豆」的 id 为 `dog`。

这是 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的衍生项目。请在**本目录**执行 `npm install && npm run build`，再用本地路径安装，例如：

```sh
dsh plugin --profile desktop add file:"$(pwd)"
```

不要 `npm install dsh-pet`，也不要在插件管理里只填包名 `dsh-pet`（那是上游官方包）。完整说明见仓库根目录的 [README.md](../README.md)、[INSTALL.md](../INSTALL.md)。归属见 [NOTICE.md](../NOTICE.md)。

许可：代码 MIT；本仓库不附带原「大肥鱼」形象素材；二创在公开渠道须署名上游仓库。
